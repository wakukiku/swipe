# Swipe

Минималистичное веб-приложение для изучения английских слов карточками.

## Что внутри

- Vue 3 + Vite
- свайп мышью и пальцем
- свайп влево — слово изучено
- свайп вправо — вернуть слово на повторение
- список изученных слов
- восстановление изученного слова обратно в очередь
- сохранение прогресса в localStorage
- адаптивная мобильная версия
- управление клавишами ← и →

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
